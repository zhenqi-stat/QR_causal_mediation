# ACTG175 data

These files accompany *Quadruply robust methods for causal mediation analysis*.

| File | Contents |
| --- | --- |
| `ACTG175_raw.csv` | Original ACTG175 data: 2,139 participants and 27 variables |
| `ACTG175_analysis.csv` | Analysis sample: 780 participants, with treatment, 12 baseline covariates, two log mediators, log outcome, and source row |
| `ACTG175_analysis.rds` | Analysis inputs and covariate bases in the same R types and row order as `real.R` |
| `variables.csv` | Variable descriptions, coding, units, transformations, roles, and missing counts |
| `LICENSE_ACTG175.txt` | GPL-2 license distributed with the source package |

## Source

The data are distributed in `speff2trial` 1.0.5:

- Package: https://CRAN.R-project.org/package=speff2trial
- Documentation: https://cran.r-project.org/web/packages/speff2trial/speff2trial.pdf
- Source data: https://github.com/cran/speff2trial/blob/master/data/ACTG175.txt

The original data are described in Hammer SM et al. (1996), *A trial comparing nucleoside monotherapy with combination therapy in HIV-infected adults with CD4 cell counts from 200 to 500 per cubic millimeter*, New England Journal of Medicine 335, 1081-1090. The source package is distributed under GPL-2. The original numeric text and row order are preserved in `ACTG175_raw.csv`; missing values are encoded as `NA`.

## Preparation

From the reproducibility-materials directory, run:

```bash
Rscript prepare_data.R
```

This uses base R to regenerate `ACTG175_analysis.csv` and `ACTG175_analysis.rds` under `output/data_preparation/`. The selection is `offtrt == 0`, `r == 1`, and `arms != 3`, with the original row order preserved. The sample contains 253 control and 527 treated participants. The selected analysis variables have no missing values.

`A = treat`. The baseline covariates are `age`, `wtkg`, `karnof`, `cd40`, `cd80`, `hemo`, `homo`, `drugs`, `race`, `gender`, `str2`, and `symptom`. The mediator variables are `M1 = log(cd420)` and `M2 = log(cd820)`; the outcome is `Y = log(cd496)`. `source_row` is the one-based row number in the original data.

The RDS also contains the polynomial and interaction bases generated by `configurations/real_2_data_generate.R`, including the QR mediator basis formed after taking logs. These inputs match the preprocessing in `real.R`. Scaling and sample splitting are performed within `real.R`.

Simulation observations are generated by `simu_1.R` through `simu_6.R`. Their DGPs and finite-pool targets are documented in `DATA_DICTIONARY.md` in the parent directory.
